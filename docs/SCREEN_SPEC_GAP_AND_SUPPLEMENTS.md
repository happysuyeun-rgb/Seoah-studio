## 4. 보완 작업 우선순위 제안

### 4.1 즉시 적용 권장 (화면 설계 충족)

1. **SC-02** 로그인: "← 홈으로" 링크 추가  
2. **SC-09** 결제 완료: 완료 체크 아이콘(페이드인) + 이메일 발송 안내 문구  
3. **SC-14** 404: `Route path="*"` 시 전용 NotFound 페이지 렌더, "홈으로 이동" 링크

### 4.2 단기 (UX·스펙 정합)

4. **SC-05** 업로드: 선택 템플릿 사이드바(썸네일·이름·템플릿 변경)  
5. **SC-05** 업로드: 글자 수 카운터 + 드래그앤드롭  
6. **SC-08** 결제: 결과물 썸네일(미니 미리보기) + 결제 수단 안내 문구  
7. **SC-10** 마이페이지: 프로필 헤더(아바타·이름·이메일) + hash 탭(#projects, #downloads)  
8. **SC-03** 갤러리: 스켈레톤 로딩 6개 카드  
9. **SC-01** 홈: 카테고리 카드 템플릿 수 뱃지

### 4.3 선택 (설계 보완)

10. **SC-01** 예시 결과물: 플레이스홀더 → 실제 결과물 스크린샷  
11. **SC-10** 프로젝트 카드: 썸네일 영역에 템플릿/결과 이미지  
12. **SC-11** 고객지원: 히어로 문구 "무엇을 도와드릴까요?" + 문의 목록 비밀글 아이콘  
13. **SC-13** 관리자: 주문 테이블에 이메일·플랜 컬럼  
14. **F-031** 1:1 문의: 유형(드롭다운) + DB type 컬럼
