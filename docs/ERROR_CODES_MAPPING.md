# 에러 코드 매핑

E-001~E-052 전체 에러 코드. 심각도별: **Critical**·**High** — 콘솔 로그 + 관리자 알림 권장.

---

## 인증 (E-001 ~ E-005)

| 코드 | HTTP/영역 | 발생 조건 | 사용자 메시지 | 처리 방법 | 심각도 |
|------|-----------|-----------|---------------|-----------|--------|
| E-001 | 401 인증 | OAuth 인증 서버 오류 | 로그인 서버에 일시적 오류가 발생했습니다 | 에러 토스트 + 재시도 버튼. /login 유지 | High |
| E-002 | 400 인증 | 콜백 URL 파라미터 손상 | 로그인 처리 중 오류가 발생했습니다 | 홈 리디렉션 + 에러 토스트 | Medium |
| E-003 | 401 인증 | 세션 만료 중 보호 라우트 접근 | 로그인이 필요합니다 | returnTo 저장 후 /login 리디렉션 | Medium |
| E-004 | 401 인증 | 세션 만료 중 Edge Function 호출 | 인증이 만료되었습니다. 다시 로그인해주세요 | Edge Function 401 응답 → /login 리디렉션 | High |
| E-005 | 403 인증 | 비관리자의 /admin 접근 | 접근 권한이 없습니다 | 홈 리디렉션. 로그 기록 | Medium |

## Edge Function 에러 코드 (API 응답용)

| 코드 | 사용자 메시지 (참고) |
|------|----------------------|
| INVALID_PROJECT_ID | projectId 형식 오류 또는 미존재 |
| UNAUTHORIZED | 로그인이 필요합니다. |
| FORBIDDEN | 접근 권한이 없습니다. |
| AI_TIMEOUT | 처리 시간이 초과되었습니다. 다시 시도해 주세요. |
| PARSE_FAILED | 파일을 읽을 수 없습니다. 텍스트를 직접 입력해 주세요. |
| INTERNAL_ERROR | 요청 처리에 실패했습니다. |
| AI_UNAVAILABLE | AI 처리에 실패했습니다. 잠시 후 다시 시도해 주세요. |
| INVALID_PARAMS | 필수 정보가 누락되었습니다. |
| AMOUNT_MISMATCH | 결제 금액이 일치하지 않습니다. 고객센터로 문의해 주세요. |
| ALREADY_PAID | 이미 결제가 완료된 주문입니다. |
| PORTONE_ERROR | 결제 서비스 연결에 실패했습니다. |
| DB_ERROR | 주문 처리에 실패했습니다. |
| NOT_PAID | 결제 완료된 주문이 없습니다. |
| FILE_NOT_FOUND | 다운로드 파일을 찾을 수 없습니다. |
| INVALID_EMAIL | 이메일 형식이 올바르지 않습니다. |
| RESEND_ERROR | 이메일 발송에 실패했습니다. |
| URL_GENERATE_FAILED | 다운로드 링크 생성에 실패했습니다. |
| PORTONE_CANCEL_FAILED | 환불 API 연동에 실패했습니다. 수동 처리 후 관리자 화면에서 상태를 업데이트해 주세요. |
| REFUND_ERROR | 환불 API 호출 중 오류가 발생했습니다. |
